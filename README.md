# Тренировки: дневник для iPhone (PWA)

Дневник силовых тренировок, кардио, питания и веса. Программа и формулы взяты из Excel-файла `cycle1.xlsm`
(лист «1 в день»: 3 дня в неделю × 12 микроциклов). Данные хранятся только на телефоне.

## Запуск

Нужен любой статический сервер, например:

```sh
python3 -m http.server 8000      # затем открыть http://localhost:8000
```

Сборки нет: чистый HTML / CSS / JavaScript (ES-модули).

## Установка на iPhone

1. Выложить папку на статический хостинг (GitHub Pages, Cloudflare Pages и т. п.).
2. Открыть ссылку в Safari → «Поделиться» → «На экран „Домой“».
3. Данные хранятся в IndexedDB этого телефона. Делай экспорт (Ещё → Настройки) раз в пару недель.

## Нейросеть-помощник

Ещё → «Тренер-нейросеть». Работает с любым сервисом в формате OpenAI: Gemini, DeepSeek, Groq, OpenRouter, Ollama или свой адрес.
Запросы идут прямо из телефона, своего сервера нет. Ключ хранится отдельно (`state.secrets`) и не попадает в экспорт. В запрос уходит только текстовая сводка;
блоки (профиль, тренировки, питание, вес) можно отключить, а точный текст запроса посмотреть в приложении.
Нейросеть предлагает изменения ПМ (до ±5 %) и калорий (до ±300 ккал), приложение проверяет границы, а применяются они только после подтверждения.

## Тесты

```sh
node --test tests/engine.test.mjs tests/nutrition.test.mjs tests/ai.test.mjs
```

Тесты сверяют расчётное ядро (`src/engine.js`) со значениями из Excel (`tests/golden.json`): веса, тоннаж, КПШ,
относительная интенсивность, Инт.Ф+Б и время по всем 12 микроциклам. Отдельно проверяются порядок упражнений, прирост ПМ, расчёт калорий и лимит подходов у добавленных упражнений.

## Обновление данных из Excel

```sh
python3 -I tools/extract_program.py cycle1.xlsm
```

Скрипт пересоздаёт `src/data/*.js` и `tests/golden.json`. Файл `.xlsm` в репозиторий не добавляй (см. `.gitignore`).

## Устройство

| Файл | Что делает |
|---|---|
| `src/engine.js` | расчёт весов и показателей, расписание, кардио, калории, тренд веса |
| `src/exercises.js` | каталог упражнений, коэффициенты ПМ, вывод профилей нагрузки для новых упражнений |
| `src/session.js` | состояние тренировок: снимки планов, факт, статусы, сводки |
| `src/nutrition.js` | база продуктов, приоритеты по приёмам, сырой / готовый вес, универсальное меню, учёт съеденного |
| `src/controls.js` | свои списки выбора и календарь вместо системных; диалоги подтверждения в `src/ui.js` |
| `src/art.js` | иконки, иллюстрации (SVG), кольца прогресса, анимации, экран «Тренировка завершена» |
| `src/ai.js`, `src/report.js` | запросы к нейросети, проверка предложений, сводка для запроса |
| `src/store.js` | хранилище (IndexedDB), экспорт / импорт |
| `src/pages/*` | экраны |
| `sw.js` | офлайн-кэш; при изменении файлов поменяй `VERSION` |
